# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

The full text is available at the link above. By participating in this project
(issues, pull requests, discussions) you agree to abide by its terms.

Reports of unacceptable behavior should be sent to the project maintainer via
the contact email listed on the maintainer's GitHub profile.
